# 培训主任实战案例库 — 加工说明

## 文件说明

- **主任实战案例库.html**：单文件交付，包含 HTML + CSS + JS 全部内联，双击即可在浏览器中运行
- **README.md**：本文件（加工逻辑文档）

## 数据来源

所有数据来自知识库 `E:\在岗主任培养方案\知识库\`，包含三个子库：

| 子库 | 路径 | 用途 |
|------|------|------|
| 01-能力库 | `知识库/01-能力库/` | 提供每个案例背后的方法论详细内容 |
| 02-实战库 | `知识库/02-实战库/` | 提供 37 个实战案例的完整内容（场景/诊断/处理流程/话术/案例/方法论） |
| 03-试题库 | `知识库/03-试题库/` | 提供考题（JSON 格式），部分题目基于能力库内容自编 |

## 数据结构

### caseLibrary（案例库）
每一条案例对应 `02-实战库` 中的一个 `.md` 文件，结构如下：

```javascript
{
  id: 数字,
  title: "案例标题（与源文件名对应）",
  category: "六大分类之一",
  icon: "emoji",
  sections: [
    { type: "scene", title: "典型场景", body: "HTML内容" },
    { type: "diagnosis", title: "问题诊断", body: "HTML内容" },
    { type: "solution", title: "处理流程", body: "HTML内容（含步骤列表）" },
    { type: "scripts", title: "关键话术", body: "HTML内容（含话术卡片）" },
    { type: "case", title: "实战案例", body: "HTML内容" },
    { type: "methodology", title: "背后方法论：XXX", body: "HTML内容" }
  ],
  competencyId: 数字,  // 关联到 competencies 数组
  questionIds: [数字]  // 关联到 questionBank 数组
}
```

### competencies（能力项/方法论库）
对应六大能力分类，每项能力的方法论完整内容来自 `01-能力库`。

### questionBank（考题库）
考题来自 `03-试题库` 的 JSON 文件，部分能力项的考题基于 `01-能力库` 内容自编。

## 更新流程

当知识库内容有更新或新增时，按以下步骤同步到 HTML：

### 1. 新增案例
**触发条件：** `02-实战库/` 中新增了 `.md` 文件

**操作步骤：**
1. 阅读新案例的 `.md` 文件，提取六个模块内容（场景/诊断/处理流程/话术/案例/方法论）
2. 在 `主任实战案例库.html` 中找到 `caseLibrary` 数组末尾（搜索 `// 2 个追加案例` 或 `3 个追加案例`）
3. 在该位置之前插入新的案例对象，遵循上述数据结构
4. 确定案例所属 `category` 和 `competencyId`
5. 为案例关联考题：从 `questionBank` 中选择相关的题目 ID 填入 `questionIds`
6. 确保 `title` 与源文件名对应

### 2. 更新已有案例
**触发条件：** 知识库中某个 `.md` 文件内容有修改

**操作步骤：**
1. 在 `主任实战案例库.html` 中搜索对应案例的 `title`
2. 逐一更新 `sections` 中对应模块的 `body` 内容
3. 如果方法论有更新，同步更新 `competencies` 数组中对应能力项的 `detail`

### 3. 新增考题
**触发条件：** `03-试题库/` 中新增或修改了考题

**操作步骤：**
1. 在 `questionBank` 数组末尾添加新的题目对象
2. 题目格式：`{id, stem, options:[], answer:索引, explanation}`
3. 将新题目 ID 关联到相关案例的 `questionIds`

### 4. 新增能力项/分类
**触发条件：** `01-能力库/` 中新增了能力分类

**操作步骤：**
1. 在 `competencies` 数组中添加新的能力项
2. 在 `categories` 数组中添加新分类名称
3. 在 `catIcons` 和 `catClassMap` 中添加对应映射
4. 在 CSS 中添加新分类的 `.case-card.cat-xxx` 样式

## 技术要点

- **存储：** 学习进度用 `localStorage` 持久化，键名 `competency_progress`
- **自测：** 每次从关联考题中随机抽取 3 题，正确率高于历史值则覆盖。题库共60题。
- **模块折叠：** 案例详情页默认只展开"典型场景"，其余模块点击标题展开/收起
- **分类筛选：** 顶部 Tab 栏按六大分类过滤，支持搜索框全文检索
- **统计面板：** 鼠标悬停查看各能力项学习进度明细
- **单文件交付：** 所有 CSS/JS 内联在 HTML 中，数据以 JS 对象硬编码，无外部依赖

## 部署方式

- 本地使用：直接双击 `主任实战案例库.html`
- 团队分享：部署到任意静态服务器（GitHub Pages、公司内网、文件服务器）
- 离线可用：无任何外部网络请求，图标用 emoji 绘制
